# Состояние КР №3

Backend реализует полный функциональный набор задания в теме управления кладбищем. Основная сущность — заявка на захоронение/бронирование; справочник — сектор; автор служебного комментария — существующий сотрудник.

Реализованы авторизация, роли, версии/конфликты изменений, внешний код, название, срочность, вычисляемый приоритет, метки, комментарии, CRUD/архив, поиск/фильтры/пагинация/сортировка, включение/отключение секторов, массовые операции, CSV preview/apply/export с обновлением по коду, аналитика и аудит.

Приложение и PostgreSQL запускаются через Docker Compose с healthcheck, Flyway V1–V4 и постоянным volume. Основной runtime использует PostgreSQL; H2 оставлена тестам и отдельному local-профилю.

Инструкция запуска: [README](../README.md). Сверка пунктов и результаты проверок: [kr3-compliance.md](kr3-compliance.md).
